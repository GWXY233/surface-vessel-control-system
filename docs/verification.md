旧记录中的布局回读、网络对账和丝印修订已经完成。发布时重新检查了原生归档 ZIP 完整性，发布副本与源文件的 SHA256 一致。独立环境导入还原、制造适配、持续电流和整机温升仍待验证。

## 软件结果

V5.4 已在经典 Nano ATmega328P、16 MHz、AVR core 1.8.8 与 Servo 1.3.0 环境编译，正常版使用 11500 字节 Flash、556 字节静态 SRAM。

- [控制模型](verification/control-model.json) 为实际 AVR HEX 与假设电机模型的回归，包含正常运行、负载变化、反馈丢失、堵转、超速、驱动故障和遥控失联等场景。
- [显示检查](verification/display-checks.json) 检查 580、595、600、601、650、1000 的数字显示、原始数值保留与 E002 优先级。
- [双舵检查](verification/servo-checks.json) 检查脉宽端点、响应、帧周期与回中。

这些模型没有拟合实船参数，不能据此保证实际最高转速、转向角、电流或5%测速精度。
