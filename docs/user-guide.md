# 从焊板到下水：RevL1 使用教程

适用硬件：69 × 54 mm、带 J10 显示屏接口的 RevL1。正常程序为 V5.4，目标 595 r/min。早期 Nano 需要反面安装的版本、L298N 单舵方案不适用这份接口方向说明。

可编辑原理图和 PCB 见 [嘉立创工程页面](https://oshwhub.com/eda_jmihncbf/project_mhcxpkbn)。2026-11-09 已提交开源，平台提示等待后台审核；若暂时打不开，可直接下载本仓库的 [原生工程](../hardware/revl1/boat-controller-revl1.epro2)。

## 1. 准备什么

| 项目 | 本样机使用的规格 |
| --- | --- |
| 主控 | 经典 Nano，ATmega328P，5 V / 16 MHz，两排各 15 针；不是 Nano Every、ESP32 或 33 系列 |
| 动力 | GA25-370-0660-EN，6 V，9.6∶1，带 A/B 霍尔编码器 |
| 舵机 | 两只角度定位型 SG90；所购实物必须明确支持接口的 6 V |
| 无线 | 已配对的 MN 原配遥控器和接收机，转向 CH1 输出常规舵机 PWM |
| 显示 | 四位 CLK/DIO 数码管模块，5 V 供电 |
| 电源 | 2S 锂电池、总电源开关、一块可调降压模块，模块输出设为 6.0 V |
| 接线 | 信号用杜邦线；电机、电池、降压电源使用合适载流量的硅胶线和可靠接头 |
| 工具 | 万用表、烙铁、助焊剂、镊子、吸锡带；首次调试建议可限流电源 |

板上 BOM 见 [bom.csv](../hardware/revl1/bom.csv)，外设见 [外部清单](../hardware/external-parts.csv)。降压模块的商品标称峰值电流不能替代持续负载实测。

J1/J4 使用板焊 XT30 封装，间距 5.0 mm、钻孔 1.8 mm。已有购买的 XT30 插脚不匹配反馈，先核对实物型号和脚径再购买、焊接或投板，不要硬压插入。J2 电机口是 3.5 mm 间距螺丝端子。

## 2. 焊接和方向

先看 [四页焊接教程 PDF](guides/assembly-revl1.pdf)。以下方向均指元件面朝上、Nano USB 朝左。

- 先焊贴片小件和芯片，再焊排母、端子及大电解电容，完成后清理并放大检查锡桥。
- U1 DRV8833、Q1 AO4407A 的 1 脚在右下；U2 NCP718 的 1 脚在左上。按芯片标记与封装 1 脚核对，不能只看字的朝向。
- U1 底部 PowerPAD 必须可靠焊接到散热接地焊盘，仅焊两排引脚不算装配完成。
- D1/D2 带条纹的阴极朝左；C5/C6 左孔为正，电解电容外壳负极条纹朝右。普通贴片陶瓷电容不分正负。
- LED 有极性，左侧 K 为阴极、右侧 A 为阳极；排母和跳帽不是同一种零件，JP1 需要内部导通的跳帽。
- Nano 从元件面插入，USB 朝左，先核对两排共 30 针的位置再上电。现版不需要反面插 Nano。

## 3. 全部接线

每次改变接线前都关闭电源并拔掉 USB。电池不能直接接 J4。

```text
电池 → 总开关 → J1 → 板上保护 → J3 → 降压模块 IN+/IN−
降压模块 OUT+/OUT−（先单独调为6.0 V）→ J4 → 驱动、舵机、板上5 V稳压
```

| 接口 | 接到哪里 | 方向和颜色 |
| --- | --- | --- |
| J1 BAT | 总开关后的 2S 电池 | 左“+”接正极，右“G”接负极 |
| J3 BUCK IN | 降压模块输入 IN+/IN− | 左“+”接 IN+，右“G”接 IN− |
| J4 6V IN | 降压模块输出 OUT+/OUT− | 左“+”接 OUT+，右“G”接 OUT− |
| J2 MOTOR | 电机两根动力线 | 下方 MOTOR_A 接样机白线，上方 MOTOR_B 接红线；两者均不能接 GND |
| J9 ENC | 电机尾部编码器四根线 | 从左到右：黑 GND、蓝 5 V、绿 A、黄 B |
| J5 RX1 | 接收机 CH1 转向 | 上 S、中 5 V、下 GND，按接收机标记一一对应 |
| J8 RX2 | 接收机 CH2 | V5.4 不用这一路控制油门，可不接 |
| J6 SV-L | 左舵机 | 上 S 接橙/黄，中 6 V 接红，下 GND 接棕/黑 |
| J7 SV-R | 右舵机 | 同 J6，两只舵机分别插各自接口 |
| J10 | 显示屏 | 从左到右 GND、5 V、DIO、CLK，分别接屏幕同名端口 |
| JP1 | Nano 电池供电通路 | 电池运行时使用导通跳帽；取下 Nano 单独接 USB 上传 |

颜色只适用于样机线束；换电机或线束时按编码器 PCB 和商品端子定义复核。编码器只接 5 V 逻辑支路，不接 6 V 舵机电源。

显示屏对应 Nano 引脚：CLK → A4，DIO → A5。这里使用固件内置 CLK/DIO 驱动，不能按 I²C 屏幕的 SDA/SCL 说明替换。更完整的针号表见 [接线文档](wiring.md)。

## 4. 首次通电前后检查

1. 断开全部电源、Nano 和外设。万用表先短接表笔，记下表笔电阻；再量 6 V 对 GND、5 V 对 GND。电容充电会使读数变化，但如果稳定读数几乎等于表笔短接值，应先排查锡桥或器件短路，不要接电池试烧。
2. 检查电解电容极性、芯片方向和接头极性。用可限流电源分段检查 J1 到 J3 的保护通路；此时 J4 没接降压输出，板上逻辑不亮并不能说明 Nano 坏了。
3. 降压模块先与板子断开，单独调为 6.0 V。断电后接 J3/J4，再上电测 J4 约 6 V、逻辑支路约 5 V。
4. 电压正常后再断电，安装 Nano 和 JP1，重上电测 Nano 本体 5V 与 GND。若掉到 2～3 V 或芯片明显发热，立即断电，排查 5 V 负载、U2 焊接和短路。
5. 之后每次断电再接入一组外设，检查加入该外设后电压是否稳定。电机和舵机最后接。

没有可限流电源时，直接用锂电池试错无法控制短路电流；先完成断电检查和独立降压调试，再做首次上电。

## 5. 上传程序

1. 取下 Nano，单独用能传数据的 USB 线接电脑。
2. Arduino IDE 安装 Arduino AVR Boards 平台及 Servo 库。
3. 打开 [Boat_Nano_595_Display600.ino](../firmware/Boat_Nano_595_Display600/Boat_Nano_595_Display600.ino)。文件应在同名文件夹内。
4. 开发板选择 Arduino Nano，处理器选择 ATmega328P，端口选择实际 Nano 串口。部分兼容板需要 ATmega328P (Old Bootloader)；用与实物匹配并能上传的选项。
5. 上传完成后拔 USB，再把 Nano 按正确方向插回主板，接好 JP1。首次测试卸桨、断开舵机连杆。

编译参数和命令见 [固件说明](firmware.md)。正常版与临时诊断版是两个独立程序，一次只上传一个。

## 6. 日常启停

先开遥控器并保持转向中位，再开电池总开关。程序确认 CH1 连续稳定约 0.5 秒后自动启动，目标参考值约 2 秒爬升至 595 r/min；油门 CH2 不控制电机。左右双舵跟随转向轮同向动作。关闭总电源停止。

首次校准舵机时拆开连杆，先找中位再安装舵臂。默认 600～2400 μs 不保证实物恰好 180°；若端点顶死、嗡鸣或电流明显增大，缩小程序端点和机械行程。

## 7. 屏幕提示与处理

| 显示 | 意思 | 优先检查 |
| --- | --- | --- |
| 0000 | 转速为零或等待启动 | 遥控器是否配对、CH1 是否接 J5、是否有有效信号 |
| ---- | 当前没有可靠转速或校准条件不满足 | 编码器参数和反馈，详见固件对应条件 |
| E001 | 启动没有确认运动，或编码器参数/反馈异常 | J9 黑蓝供电、绿 A 相；电机白红动力线；轴系是否卡滞 |
| E002 | 原始反馈达到 610 r/min，超速锁停 | 编码器换算是否正确、卸载超调、传动比及原始读数 |
| E003 | 到参考目标后连续约 3 秒未维持 570～630 r/min | 带载电压、动力接触、联轴器摩擦及电机能力 |
| E004 | 已启动后 CH1 转向信号丢失 | 遥控器、接收机供电、J5 信号与公共地 |

驱动故障也会停机，但没有单独 E005。出现锁停后关闭总开关，等屏幕熄灭并处理原因，再重启。

**普通数字显示封顶 600。实际超过 600 也可能显示 600。控制、串口与超速保护仍使用未截断的原始反馈；显示封顶不能用来证明比赛限速达标。**

## 8. 编码器和测速核对

默认使用输出轴 10 圈累计 1019 个 A 相上升沿，即每输出圈约 101.9 次计数。不要把产品页的 CPR、A/B 双相倍频值直接填进这个参数。更换编码器、减速比或传动比后必须重做标定。

断开电机动力、卸桨，把程序开头的 `ENCODER_CALIBRATION_MODE` 从 `0` 改为 `1` 后上传。此模式关闭电机和舵机驱动，屏幕显示原始累计计数。记录手转输出轴整 10 圈前后的计数差，将差值填入 `ENCODER_PULSES_NUM`，圈数填入 `ENCODER_TURNS_DEN`（样机分别为 `1019UL`、`10UL`）；再把校准模式恢复为 `0` 后上传正常运行。若输出轴与桨轴不是平均 1∶1，应直接按桨轴的已知整圈数标定计数与圈数。验证时与独立测速仪比较。

实际转速上不去时，先用 [临时诊断程序](../firmware/Boat_Nano_Drive_Diagnostic/Boat_Nano_Drive_Diagnostic.ino) 查看真实转速和交替出现的 Pxxx。P255 表示驱动指令已满，继续增加软件目标不会增加可用电机电压。应检查电源带载压降、线材、连接器和联轴器角度/阻力。诊断版目标为 600，与正常版 595 不同。

## 9. 常见现象

| 现象 | 检查顺序 |
| --- | --- |
| Nano 不亮 | J4 是否真的有降压输出 → 5 V 稳压 → JP1 是否导通 → Nano 本体 5V/GND 与插接方向 |
| 显示不亮或乱码 | J10 信号名逐线核对 → 5 V 与公共地 → 是否上传了支持显示的程序 |
| 一动舵机就重启 | 舵机是否机械顶死 → 6 V 供电压降和模块余量 → 接头/线材 → 大电容装配 |
| 舵机方向反了 | 断开连杆，在程序对应舵机反向设置中调整，再校准中位 |
| 电机转但一直 E001 | 编码器四线接法、5 V、A 相焊接和计数参数；不必先提高电压 |
| 转速比预期差一倍/数倍 | A 相上升沿计数口径、减速输出轴圈数和桨轴传动比 |
| 短路蜂鸣 | 改用电阻档并与表笔短接值比较；蜂鸣阈值不等于零欧，板内并联路径会影响测量 |

电气验证边界和未验证项见 [验证范围](verification.md) 与 [已知问题](known-issues.md)。焊接合格、DRC 为零和实板额定负载能力是不同的检查结果。
