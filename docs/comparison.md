# 两代电控方案对比

旧方案来自仓库最初提交 `cbf93ed3fa788c230c6470cf0aaf1998bd2d8026`，现保留在 [legacy/l298n-single-servo](../legacy/l298n-single-servo/)。原始提交历史继续保留。

| 项目 | 早期模块方案 | 当前 RevL1 方案 |
| --- | --- | --- |
| 电路载体 | Nano、L298N、降压模块分立接线 | 自研 PCB，Nano 排母插接，外接一块降压模块 |
| 电机驱动 | 外接 L298N 模块 | 板载 DRV8833 |
| 转向 | 单只 SG996R，直接接接收机 CH1 | 双 SG90，CH1 输入 Nano 后生成两路舵机信号 |
| 速度输入 | CH2 油门控制 | 总电源开关自动启停，目标 595 r/min |
| 测速 | 早期已验证版为开环控制 | 编码器 A 相上升沿测速，PI 调节 PWM |
| 显示 | 原系统未集成显示接口 | J10 外接四位数码管，V5.4 数字显示封顶 600 |
| 供电 | 2S 接 L298N 动力端，外接 5 V 支路 | 外接 6 V 主供电，板载 5 V 逻辑支路 |
| 异常处理 | 失控停机、换向延时 | 编码器异常、超速、转向失联及驱动故障锁定 |
| 复用方式 | 保留原接线和原代码一起使用 | 按当前接线表和当前固件整套使用 |

两套方案的 Nano 引脚、电源路径和舵机接法不同。对比时以各自版本的接线与程序为一组。
