# 完整资料包下载

[下载 v0.1.0 完整 ZIP](https://github.com/GWXY233/surface-vessel-control-system/releases/download/v0.1.0/surface-vessel-control-system-RevL1-V5.4-v0.1.0.zip)

下载后完整解压，双击根目录 `START_HERE.html`，打开离线使用入口。

资料包包含 RevL1 原生 PCB 与原理图工程、板上 BOM、外部模块清单、机械尺寸、布线预览、原生 DRC 记录、V5.4 正常程序、临时诊断程序、两页使用说明 PDF、四页焊接教程 PDF，以及早期 L298N 单舵方案。

两页使用说明对应 V5.4 的 595 r/min 目标、0.5 秒启动等待及普通数字显示封顶 600 的行为。焊接教程用于 RevL1 硬件装配，软件行为按新版使用说明执行。

原生 `.epro2` 归档内含原理图、PCB 和相关工程库资源。当前发布包未提供独立 Gerber 与贴片坐标，制造数据应在核对工程和 XT30 实物插脚适配后从 EDA 导出。

包内 `MANIFEST.sha256` 记录每个交付文件的 SHA256。Release 同时提供 ZIP 的 SHA256 校验文件。旧方案的程序与文档继续保留，按各自版本使用。
