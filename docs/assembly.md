# 焊接与首次通电

配套 [两页使用说明 PDF](guides/quick-start-v54.pdf) 对应当前 V5.4 的接线、启停与报码，可按 A4 双面打印。

[四页焊接教程 PDF](guides/assembly-revl1.pdf) 包含板上元件规格、方向示意、接口表和分段测电源流程。该教程对应 RevL1 硬件，其固件相关描述早于 V5.4，当前启动和显示行为以 [固件说明](firmware.md) 为准。

元件面观察、Nano USB 朝左时，U1 DRV8833 与 Q1 AO4407A 的 1 脚在右下，U2 NCP718 的 1 脚在左上。C5/C6 左孔正极、右孔 GND，负极条纹朝右。D1/D2 阴极条纹朝左。

先焊贴片并检查锡桥，再焊插件和电解电容。U1 的底部 PowerPAD 需要可靠焊接到 GND，外侧引脚与底盘都参与装配验证。

1. 全部断电，先记录万用表表笔短接电阻，再检查 6 V、5 V 与 GND 是否有稳定低阻短路。
2. 首次用可限流电源，外设、Nano 和 JP1 均先断开，检查 J1 到 J3 的入口保护路径。
3. 单独调外接降压模块至 6.0 V，断电后连接 J4，检查板上约 5 V 逻辑电源。
4. 分别接入 Nano、接收机、舵机、显示屏、编码器与电机，每次接线前断电。
5. 初次运行先卸桨并断开舵机连杆。当前固件在 CH1 有效后会自动启动电机。

XT30 引脚孔径与具体板焊型号的匹配需先核实，详见 [已知问题](known-issues.md)。
